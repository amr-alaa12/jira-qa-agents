# Paired dataset: user stories with their test cases

**Status: not found yet — to be completed by Omar.**

This is a different dataset from `requirements.csv`: it should pair each user
story (ideally with its acceptance criteria) with the test cases written for it,
ideally with test inputs and expected outputs. Amr can use it for the comparison
and Ahmed for evaluation.

Where to search: Kaggle, Hugging Face Datasets, Zenodo, GitHub, and the published
code and data of research papers on generating test cases from user stories.

| Item | What to write |
|---|---|
| Name and link | exact dataset title and URL |
| Source | who published it; paper citation if any |
| Licence | e.g. CC-BY-4.0, MIT, or "unknown" |
| Fields | every column (story, acceptance criteria, test steps, input, expected output, labels) |
| Missing | which of our needs it lacks (e.g. no expected outputs, no labels) |
| Example | one story with its test cases, copied as JSON |
| Fit note | 3–5 sentences: can Ahmed or Amr use it, and for what (training, comparison, evaluation) |

Do not replace `requirements.csv` with this dataset until the team agrees.
